## ppdelay

ppdelay is a simple pulse delay generator.

Command line arguments:

* ``-p``, ``-m``: trigger settings (pattern and mask)
* ``-delay``: delay between triggering and output pulse, in seconds
* ``-duration``: duration of the pulse, in seconds
* ``-v1``: pulse on value
* ``-v0``: pulse off value
* ``-t``: final value

All standard trigger combiner settings are also accepted.
